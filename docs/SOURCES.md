# Sources for figures and quotes

Every figure or quote that the README uses has a row here, and the README sentence that uses it ends with the row's tag, for example `[S1]`. Loss figures live only in this file. The Wording rule column is binding for the README and for every other doc. Tiers follow the source audit: T1 is a peer reviewed paper, a final standard, a primary advisory or an official post-mortem; T2 is an established lab preprint, an established security firm or official documentation; T3 is a little-known preprint, a vendor self-evaluation or a small repository; T4 is press or social media. Where the AIRLOCK literature map and the source audit differ, the audit's wording fix is the one used here.
